# 학교 교통 시뮬레이션 시스템

## 개요
학교 교통봉사의 문제점을 해결하기 위해 개발된 경로 기반 교통 시뮬레이션 시스템입니다.

## 주요 기능

### 1. 경로 기반 차량 이동
- 실제 학교 지도를 배경으로 하여 좌표 기반 도로 구현
- 입차 경로, 출차 경로 분리
- 차량은 반드시 도로 위에서만 이동

### 2. 차량 유형 및 주차 시간
- **TYPE A**: 짧은 주차 시간 (300프레임 ≈ 5초)
- **TYPE B**: 긴 주차 시간 (600프레임 ≈ 10초)

### 3. 지능형 교통 제어
- 대기 차량 수 모니터링
- 기준 차량 시스템을 통한 안정적인 흐름 제어
- 입차/출차 자동 제어

### 4. 차량 상태 관리
```
ENTERING (입차) → PARKING (주차) → WAITING (대기) → EXITING (출차) → COMPLETED (완료)
```

## 작동 원리

### 정상 입차 단계
1. 차량이 일정 주기로 자동 생성
2. 입차 경로를 따라 이동
3. 주차 구역에 도달 후 주차

### 교통 제어 알고리즘
1. **대기 차량 모니터링**: 출차 경로 대기 지점의 차량 수 계산
2. **입차 중단**: 대기 차량 수 ≥ 기준(3대)이면 새로운 차량 입차 중단
3. **기준 차량 설정**: 마지막 입차 중인 차량을 기준 차량으로 설정
4. **출차 허용**: 기준 차량이 주차 상태로 전환되면 모든 대기 차량 출차 시작
5. **주기 반복**: 모든 차량이 출차 완료 후 초기 상태로 돌아감

## 화면 구성

### 색상 코드
- 🟢 **녹색**: 입차 중인 차량
- 🔵 **파란색**: 주차 중인 차량
- 🔴 **빨간색**: 출차 중인 차량
- 🟡 **노란색**: 대기 중인 차량
- 🟣 **마젠타**: 기준 차량 (테두리)
- 🟠 **주황색**: 대기 지점

### 요구사항

- Pygame 2.5.2

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

## 시뮬레이션 매개변수

### 구성 가능한 값 (main.py 수정)
- `SCREEN_WIDTH`, `SCREEN_HEIGHT`: 화면 크기
- `FPS`: 초당 프레임 수
- `generation_interval`: 차량 생성 주기
- `max_waiting_vehicles`: 대기 차량 최대 기준 수
- `parking_time_max`: 각 차량 유형의 주차 시간
